# How to Deploy Sensei Unified Self-Check System

## Prerequisites
- Python 3.11+
- pip
- GitHub account with repo creation permissions

## Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/your-username/Sensei-Unified-Self-Check-System.git
cd Sensei-Unified-Self-Check-System
```

### 2. Create virtual environment and install dependencies
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# or
.\venv\Scripts\activate  # Windows

pip install -r requirements.txt
```

### 3. Run the application

#### CLI Mode (Generate problems directly)
```bash
python app.py generate --type short_answer --difficulty easy --topic linear_equation --count 5
python app.py generate --type numerical --difficulty medium --topic triangle_area --count 3
python app.py generate --type numerical --difficulty hard --topic circle --count 2
```

#### Server Mode (Start API server)
```bash
python app.py server --port 8000
```

### 4. Access the API
Open your browser: http://localhost:8000/docs

## Docker Deployment

### Build and run with Docker
```bash
docker build -t sensei-unified .
docker run -p 8000:8000 sensei-unified
```

### Run with Docker Compose
```bash
docker-compose up -d
```

## GitHub Pages Deployment

The API documentation will be available at: `http://localhost:8000/docs`

Swagger UI is auto-generated by FastAPI.

## Configuration

### Customize API Endpoint
```bash
curl -X POST http://localhost:8000/configure/api \
  -H "Content-Type: application/json" \
  -d '{
    "generator": "algebra",
    "endpoint_url": "https://your-api-service.com/v1",
    "api_key": "your_api_key_here",
    "timeout": 60,
    "rate_limit": 50
  }'
```

## Available API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | / | Server status |
| GET | /generators | List available generators |
| POST | /generate/problem | Generate problems |
| POST | /generate/testcase | Generate test cases |
| POST | /configure/api | Configure custom API |
| GET | /problems/{id} | Get specific problem |
| POST | /validate | Validate answer |

## Problem Types Supported

### Algebra Generator
- `linear_equation` - Linear equations
- `quadratic_equation` - Quadratic equations
- `factoring` - Factoring polynomials
- `system_of_equations` - Systems of equations

### Geometry Generator
- `triangle_area` - Triangle area calculations
- `circle` - Circle area and perimeter
